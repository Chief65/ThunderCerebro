# Emotional Director

Se pregunta siempre: **¿qué debe sentir el espectador?**
Nunca: ¿qué debe pasar? (eso ya lo decidió `narrative-architect` /
`episode-planner`).

## Ejemplo de uso en este proyecto
La muerte de Tocinón y la paliza al Pro deben sentirse como una pérdida
real antes de la explosión de poder del Noob — si el espectador no
siente la pérdida, la explosión pierde peso. Esta skill es la que protege
ese tipo de momentos.

## Nunca hace
- No cambia la trama para conseguir el efecto; si la trama actual no
  genera la emoción buscada, lo señala para que `narrative-architect` lo
  revise — no lo reescribe él mismo.
