# ThunderMC — Proyecto Activo

## Descripción
Network de Minecraft (Paper 1.21.11+) con una única modalidad: **Survival Custom**.

Survival modificado con mecánicas adicionales:
- Dungeons
- Encantamientos custom
- Objetos custom

## Objetivos

### Corto plazo — El "Core del Éxito"
1. Crear una estructura de modalidad **replicable** — una fórmula probada en entorno real
2. Todas las mecánicas **estudiadas y cohesionadas** para un modo armónico
3. Enfoque en **farmeo + interacción social** → máxima retención de jugadores
4. **Ingresos estables** del servidor como objetivo prioritario
5. Seguimiento con métricas reales, jugadores reales, análisis continuo

### Medio plazo — Escalamiento
- Servidores estables + ingresos recurrentes consolidados
- Replicar el core en futuros modos de juego (ahorro de tiempo y trabajo)

### Largo plazo — Expansión
- Crear **Relevate** (grupo/holding tecnológico-digital)
- Expansión a plataformas menos nicho (Roblox, SaaS)
- Usar capital generado en ThunderMC como base de inversión

## Versión técnica
- Paper 1.21.11 o superior
- Modalidad actual: Survival Custom (única)
