## 📝 Notas del Sistema

- **Plugin:** ShopGUI+ 1.113.0
- **Economía dual:** Vault ($) para todo el shop normal — PlayerPoints (⚡) solo para la tienda de Almas
- **sellPrice: -1** = el item no se puede vender (equivalente a sin precio de venta)
- **Items de tipo "command"** (spawners, llaves, protecciones) ejecutan comandos al comprar — no tienen precio de venta
- **Minas y shop son sistemas complementarios:** el Cristal Estelar se farmea en minas y se vende solo mediante /sellgui, no existe en el shop de compra
