# 🧠 Core (Datos, Analítica y Entorno)

Este es el laboratorio de datos central de ThunderMC. Aquí se almacena y analiza toda la información viva del entorno del servidor, de forma independiente al desarrollo técnico de los plugins.

## Contenido

- **`/Economia_Actual/`**: Registros de la inflación, balance de riqueza, transacciones importantes y salud de la economía in-game.
- **`/Pruebas_y_Experimentos/`**: Documentación de mecánicas probadas (ej. cambios de rates, nuevos items), tests A/B y cómo la comunidad reacciona a ellos.
- **`/Datos_del_Entorno/`**: Logs analíticos, métricas de rendimiento del ecosistema, tiempos de juego y demografía del servidor.
