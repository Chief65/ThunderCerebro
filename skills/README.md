# Catálogo Maestro de Habilidades (Skills)

Este directorio centraliza todas las habilidades y capacidades operativas del ecosistema **ThunderCerebro**.

---

## 🧭 ¿Cómo usar las Skills?
- Cada skill contiene instrucciones específicas de rol, metodología o workflow en su archivo `SKILL.md` o `.md`.
- Cuando el usuario solicite un rol o tarea (ej: *"Actúa como lore-keeper"*, *"Inicia modo-estudio"*, *"Ejecuta cierre-sesion"*), el agente consulta y aplica la skill correspondiente.
- Nuevas skills pueden añadirse creando una subcarpeta con `SKILL.md` o un archivo `.md`.

---

## 📂 Catálogo por Categorías

### 🧠 Productividad, Aprendizaje y Cognición
- **`active-recall/`**: Metodología de recuerdo activo y autoevaluación.
- **`cerebro-digital/`**: Gestión de conocimiento personal (PKM) y convenciones de bóveda.
- **`cierre-sesion/`**: Protocolo de recapitulación, commit y cierre ordenado de sesiones de trabajo.
- **`modo-estudio/`**: Aprendizaje acelerado y síntesis estructurada.
- **`modo-productivo/`**: Enfoque de alta concentración y priorización de tareas.
- **`generador-ejercicios/`**: Creación de pruebas prácticas y retos de aprendizaje.

### 📝 Obsidian & Gestión de Bóveda
- **`obsidian-capture/`**: Captura rápida de ideas, enlaces y notas volátiles.
- **`obsidian-daily/`**: Estructuración y gestión de notas diarias.
- **`obsidian-inbox/`**: Procesamiento y clasificación del buzón de entrada.
- **`obsidian-syntax/`**: Directrices de formato, enlaces `[[wikilinks]]` y YAML frontmatter.

### 🛠️ Ingeniería, Arquitectura y Producto
- **`arquitectura-datos/`**: Diseño y modelado de datos y esquemas.
- **`documentacion-decisiones/`**: Creación de registros de decisiones arquitectónicas (ADR).
- **`instalar-mcps/`**: Guía y catálogo para configuración de servidores Model Context Protocol (MCP).
- **`investigacion-problemas/`**: Diagnóstico estructurado de bugs y análisis de causa raíz.
- **`lanzamiento-producto/`**: Framework integral de lanzamiento y go-to-market.
- **`scaffolding-proyecto/`**: Generación de plantillas y estructura inicial de repositorios.
- **`startupsurvival/`**: Estrategias de supervivencia, agilidad y optimización para startups y proyectos lean.

### 🌐 Desarrollo Web, UI/UX & Frontend (`web/`)
- **`emil-design-eng/`**: Filosofía de ingeniería de diseño e interacción (Emil Kowalski). Pulido visual, animaciones fluidas con propósito, microinteracciones y calidad de componentes.
- **`taste-skill/`**: *Anti-slop frontend framework*. Inferencia de contexto, diseño de landing pages/portafolios no genéricos, tipografía avanzada y sistemas de diseño con criterio estético.
