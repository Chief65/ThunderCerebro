# Episode Planner

Transforma una idea ya validada (canon-check y character-check hechos) en
una estructura de episodio:

```
Cold Open → Acto I → Acto II → Clímax → Resolución → Gancho (post-credit)
```

## Referencia de estilo
El guion del Episodio 1 (`UnderDog/10_Scripts/Episodio_01_Guion.md`) es el
patrón de referencia: introducción tranquila del personaje, escalada
cómica de intentos fallidos (estilo Correcaminos y Coyote), aparición de un
personaje que cambia la situación, y gancho final con un elemento de
misterio (el hombre trajeado con el catalejo).

## Nunca hace
- No decide si algo es canon (`lore-keeper`).
- No escribe el diálogo final palabra por palabra (`dialogue-writer`).
